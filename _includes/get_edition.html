{%- comment -%} Edition of the current page, e.g. "2025" for /2025/talks/x/ (Front Matter `edition`, set per folder via `defaults`; none: the current edition). The current edition is the first of `conference.editions` with `current: true`, else the first one. Without `conference.editions` there is a single edition: `edition` is nil and everything below is the site's own. Sets: - edition, edition_config (its `editions` entry), edition_current_id, edition_current (true on the current edition) - edition_base: URL prefix of the edition's pages, e.g. "/2025" (or "") - edition_documents: folder of linked files, e.g. "/2025/documents" - edition_talks, edition_speakers, edition_program - edition_rooms: by `order`, else as they first appear in the program - edition_title, edition_description and per sub-setting (e.g. `navigation.logo`): edition_link_preview, edition_schema_org, edition_nav_logo, edition_nav_links, edition_nav_breakpoint, edition_nav_editions, edition_info_bars, edition_info_modals, edition_tracks, edition_tags: the edition's setting, else the site's - edition_live: `conference.live` on the current edition, else nil
